
# PF03 - Actividad 1: TDD + Node + CI
# ANGOGA2627

Proyecto del módulo Proyecto Intermodular de 2.º DAW para practicar el desarrollo dirigido por pruebas (TDD) con Node.js

## Funciones

- `fibonacci(n)`: calcula el término correspondiente de la sucesión de Fibonacci.
- `esPinValido(pin)`: comprueba si un PIN cumple los requisitos establecidos.

## Tecnologías

- Node.js
- JavaScript
- Vitest
- Chalk
- Git y GitHub 
- GitHub Actions 



El desarrollo de las funciones seguirá las fases RED, GREEN y REFACTOR.
